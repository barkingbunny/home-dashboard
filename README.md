# home-dashboard

Úvodní stránka domácího displeje: starý tablet na zdi zobrazuje v kiosk prohlížeči
jednu statickou stránku s dlaždicemi.

Stránka poběží na GitHub Pages: <https://barkingbunny.github.io/home-dashboard/>

## Co bude zobrazovat

- den, datum a kdo má svátek
- digitální hodiny
- aktuální počasí (stanice ČHMÚ Praha-Libuš)
- předpověď počasí na dnešek pro Prahu-Lahovice (Open-Meteo)
- rozcestník na další stránky, např. teploty vody

## Technicky

Čisté HTML, CSS a JavaScript bez build kroku a bez knihoven. Data si stránka bere přímo
z veřejných API, server není potřeba. Cílové zařízení má starý prohlížeč (odpovídá Chrome 95).

## Stav

Repozitář je založený, stránka se teprve připravuje.
